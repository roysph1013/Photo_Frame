# 參數相框 Photo Frame

在手機瀏覽器幫照片加上外框與拍攝參數（EXIF）的單頁工具，不需安裝、可離線使用。

## 功能

- 自動讀取 EXIF：相機型號、鏡頭、焦段、光圈、快門、ISO、拍攝時間
- 8 款版型：底部白條、白框左右、置中分隔、置中陰影、模糊背景、三欄白條、型號分隔、參數膠囊
- 成品比例：原始、1:1、4:5、3:4、2:3、9:16、3:2、16:9，外框不變、照片自動裁切，可放大與移動
- 所有數據可手動修改，每一項都能單獨開關
- 33 款英文字體與粗細選擇
- 資訊位置微調：上下左右位移、邊距、行距、間距、Logo 大小
- Logo 庫：可上傳自己的品牌 Logo（PNG / SVG），存在瀏覽器裡，依 EXIF 自動套用
- 輸出原始解析度 JPG，檔名為「原檔名_Frame.jpg」，重複存檔自動編號不覆蓋
- 支援資料夾存取的瀏覽器可直接存進 Frame 資料夾

## 使用方式

1. 用手機 Chrome 開啟 `index.html`（或 GitHub Pages 網址）
2. 點「選照片」，可一次選多張
3. 在下方分頁調整版型、比例、邊框、Logo 與各項數據
4. 點「下載」

## 注意

- iPhone 的 HEIC 照片請先轉成 JPG
- 字體第一次需要網路下載，離線時改用系統字體
- 地點需手動輸入，不會從 GPS 自動轉換
